# PT INFOBIT CIPTA MANDIRI - Company Website

Website perusahaan untuk PT INFOBIT CIPTA MANDIRI - Your Trusted IT Solutions Partner

## Tentang

PT INFOBIT CIPTA MANDIRI adalah reseller terpercaya untuk solusi teknologi informasi yang telah berdiri sejak tahun 2012. Kami menyediakan produk-produk IT berkualitas tinggi dari principal ternama dunia.

## Fitur Website

- **Design Modern**: Theme inspirasi dari Radiant dengan gradient dan animasi smooth
- **Responsive Design**: Tampil sempurna di semua perangkat (desktop, tablet, mobile)
- **Scroll Animations**: Efek animasi yang menarik saat user scroll
- **Contact Form**: Form kontak dengan validasi dan CAPTCHA keamanan
- **Partner Showcase**: Menampilkan semua partner dan produk yang tersedia

## Cara Menggunakan

1. Clone repository ini
2. Buka file `index.html` di browser
3. Website siap digunakan!

Untuk production:
- Upload semua file ke web hosting Anda
- Pastikan struktur folder tetap sama
- Update email di contact form jika diperlukan

## Kustomisasi

### Mengganti Warna Theme
Edit file `css/style.css` pada bagian `:root` variables:
```css
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    --accent-color: #f093fb;
}
```

### Mengupdate Informasi Perusahaan
Edit file `index.html` sesuai kebutuhan.

### Setup Email Contact Form
Untuk mengaktifkan pengiriman email otomatis:
1. Uncomment baris mailto di `js/script.js` (line 120), atau
2. Integrasikan dengan backend server (PHP, Node.js, dll)
